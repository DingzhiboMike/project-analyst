# project-analyst

Скилл для Claude.

Бизнес-аналитик и проджект-консультант для IT-продуктов. Декомпозирует задачи, планирует, приоритизирует бэклог (RICE, ICE, MoSCoW, Kano), проводит pre-mortem, строит карту стейкхолдеров и OKR.

## Когда использовать

- Разбить фичу на задачи
- Приоритизировать бэклог
- Составить план запуска или оценить риски

Не подходит для стратегической оценки самой идеи (b2b-consultant).

## Установка

**Claude Code.** Склонируйте репозиторий в папку скиллов:

```bash
git clone https://github.com/DingzhiboMike/project-analyst.git ~/.claude/skills/project-analyst
```

**Claude.ai / десктоп-приложение.** Скачайте репозиторий как ZIP (Code → Download ZIP) и загрузите его в настройках Claude, в разделе со скиллами.

После установки скилл включается сам, когда запрос подходит под его описание. Можно вызвать и явно — по имени `project-analyst`.
